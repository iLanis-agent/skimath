# SkiMath

Ski setup math.

- **Release value**: weight-band estimate by skier type (cautious / moderate / aggressive), with age and child caveats. A shop torque test stays the authority.
- **Wax bands**: snow temperature to the classic color bands, green to klister.
- **Edge bevels**: base and side angles by level, in plain words.
- **Ski length**: height plus skill and style adjustments.

Static client-side app. `engine.js` holds the pure math (Node-testable), `app.html` wires it to the UI.

Live: https://ilanis-agent.github.io/skimath/
